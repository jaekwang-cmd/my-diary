# 심플 일기장 (PWA)

사진과 함께 쓰는 일기장. 아이폰 · 안드로이드 · PC에서 같은 주소로 씁니다.
설치는 [SETUP.md](SETUP.md) 참고.

## 기능

- 리스트 / 달력 두 가지 보기
- 사진 첨부 (자동 리사이즈, 여러 장)
- `#해시태그` 자동 인식 · 본문 전문 검색
- **루틴 카탈로그** — 헬스·데이트 같은 카테고리를 직접 만들어 일기에 탭으로 붙이기
- **D-DAY** — 시작일부터 며칠, 끝났으면 총 며칠 (여러 개 동시 관리)
- **통계** — 월별 루틴 횟수, 루틴 달력, 연속 기록 (항목별로 숨기기 가능)
- 테마 컬러 19종 · 다크 모드 · 글자 크기 4단계
- 패스코드 잠금 (+ 지문 / Face ID)
- 구글 드라이브 백업 · 복원 · 자동 백업
- zip 내보내기 / 가져오기
- 오프라인 동작 (비행기 모드에서도 작성 가능)
- 광고 없음, 구독 없음

## 루틴 쓰는 법

**두 가지 방법 다 됩니다. 섞어 써도 됩니다.**

1. **탭해서 붙이기** — 일기 쓸 때 제목 아래 칩을 누르면 켜집니다.
2. **본문에 해시태그** — `오늘 3km 뛰었다 #헬스` 처럼 쓰면 자동으로 잡힙니다.

루틴마다 인식할 태그를 따로 정할 수 있습니다. (예: 이름은 `러닝`, 태그는 `달리기`)

루틴을 삭제해도 **이미 쓴 일기 내용은 지워지지 않습니다.** 통계에서만 빠집니다.

## D-DAY 표시 방식

| 상태 | 표시 |
|---|---|
| 시작일이 과거, 종료일 없음 | `D+411` · 412일째 |
| 시작일이 미래 | `D-19` · 시작 예정 |
| 종료일 있음 | `총 340일` · 2024.3.2 ~ 2025.2.4 |

## 데이터가 저장되는 곳

| 위치 | 내용 |
|---|---|
| 기기 안 (IndexedDB) | 일기 본문, 사진 원본 |
| 기기 안 (localStorage) | 설정, 루틴 카탈로그, D-DAY |
| 본인 구글 드라이브 | `심플일기장 백업` 폴더 (연동했을 때만) |
| 그 외 서버 | **없음** — 일기가 외부로 나가지 않습니다 |

루틴과 D-DAY도 드라이브 백업 · zip에 함께 들어갑니다.
여러 기기에서 고쳤다면 **마지막에 고친 쪽**의 목록이 남습니다.

> 아이폰 Safari는 앱을 오래 안 쓰면 저장 데이터를 정리할 수 있습니다.
> **자동 백업을 켜두시는 것을 권합니다.**

## 파일 구조

```
index.html               화면 구조
css/style.css            테마 · 레이아웃
js/app.js                화면 동작 전체
js/db.js                 IndexedDB 저장소 · 이미지 처리
js/settings.js           설정값 · 테마 19종 · 패스코드 해시
js/drive.js              구글 드라이브 동기화
js/config.js             구글 클라이언트 ID  ← 여기만 수정하면 됨
js/demo.js               미리보기용 샘플 데이터 (?demo 로 접속할 때만)
js/vendor/zip.js         zip 읽기/쓰기
sw.js                    오프라인 캐시
manifest.webmanifest     앱 정보
icons/                   앱 아이콘
icons/splash/            아이폰 시작화면 (기종별 24장)
```

## 주소 뒤에 붙일 수 있는 옵션

| 주소 | 하는 일 |
|---|---|
| `?demo` | 샘플 일기 18건과 D-DAY 3개를 채워 넣습니다 (일기가 하나도 없을 때만) |
| `?iosbanner` | 아이폰 설치 안내 배너를 PC에서도 띄워 봅니다 |

## 아이폰 대응

- 기종별 시작화면 24장 (라이트/다크 각각) — 안드로이드는 manifest로 자동 생성돼 불필요
- 입력창 글자를 최소 16px로 고정 — 아이폰이 탭할 때 화면을 확대하는 것 방지
- `navigator.storage.persist()` 로 저장 데이터 정리 방지 요청
- 알림은 서비스워커 방식 우선 (아이폰은 `new Notification()` 미지원)
- Safari로 열었는데 설치 안 했으면 안내 배너 표시

시작화면을 다시 만들려면 `make_splash.py` 를 실행하면 됩니다.

## 여러 기기에서 쓸 때

같은 구글 계정으로 연결하면 일기가 **합쳐집니다**.
같은 일기를 양쪽에서 고쳤다면 **나중에 저장한 쪽**이 남습니다.
