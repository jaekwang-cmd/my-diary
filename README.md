# 심플 일기장 (PWA)

사진과 함께 쓰는 일기장. 아이폰 · 안드로이드 · PC에서 같은 주소로 씁니다.
설치는 [SETUP.md](SETUP.md) 참고.

## 기능

- 리스트 / 달력 두 가지 보기
- 사진 첨부 (자동 리사이즈, 여러 장)
- `#해시태그` 자동 인식 · 전문 검색
- 테마 컬러 19종 · 다크 모드 · 글자 크기 4단계
- 패스코드 잠금 (+ 지문 / Face ID)
- 구글 드라이브 백업 · 복원 · 자동 백업
- zip 내보내기 / 가져오기
- 오프라인 동작 (비행기 모드에서도 작성 가능)
- 광고 없음, 구독 없음

## 데이터가 저장되는 곳

| 위치 | 내용 |
|---|---|
| 기기 안 (IndexedDB) | 일기 본문, 사진 원본 |
| 본인 구글 드라이브 | `심플일기장 백업` 폴더 (연동했을 때만) |
| 그 외 서버 | **없음** — 일기가 외부로 나가지 않습니다 |

> 아이폰 Safari는 앱을 오래 안 쓰면 저장 데이터를 정리할 수 있습니다.
> **자동 백업을 켜두시는 것을 권합니다.**

## 파일 구조

```
index.html               화면 구조
css/style.css            테마 · 레이아웃
js/app.js                화면 동작 전체
js/db.js                 IndexedDB 저장소 · 이미지 처리
js/settings.js           설정값 · 테마 19종 · 패스코드 해시
js/drive.js              구글 드라이브 동기화
js/config.js             구글 클라이언트 ID  ← 여기만 수정하면 됨
js/vendor/zip.js         zip 읽기/쓰기
sw.js                    오프라인 캐시
manifest.webmanifest     앱 정보
icons/                   앱 아이콘
```

## 여러 기기에서 쓸 때

같은 구글 계정으로 연결하면 일기가 **합쳐집니다**.
같은 일기를 양쪽에서 고쳤다면 **나중에 저장한 쪽**이 남습니다.
